# Module 7: Software Development Process and Quality Management (DS Track)

**Year:** 3 | **Code:** 07.DS | **Learning Line:** Professional Practice Line | **ECs:** 12.5

Develops software development process management and quality practice for Year 3, building on Module 5 (applied data science) and Module 6 (team inquiry) — prepares learners to manage data science development work via appropriate methodologies and improve delivery quality through disciplined professional practices. Content, connection with the Research Practice Line, forms of learning, intended competency (Software development process management: apply appropriate methodologies e.g. agile; use version control/testing to enhance quality), 8-week planning (SDLC and method selection; Agile; Lean; Planning/Monitoring/Delivery Control; Version Control and Code Review; Testing Strategy and Software Reliability; Continuous Integration and Quality Controls; Integrated Process and Quality Management Project), weekly study load (41 hrs), and assessment structure are identical to the Applied Machine Learning track's Module 7 (see `../applied-machine-learning/Module 7 - Software Development Process and Quality Management and AI-ML Solution Design using Action Inquiry.md`), except this DS-track version's title does **not** carry the ML track's additional "AI/ML Solution Design using Action Inquiry" claim — it is titled simply "Software Development Process and Quality Management."

## Passing Criteria

≥75% low-stake evidence, ≥75% medium-stake Module Project, Certification VIVA passed — contributes to the Certificate 3 portfolio.
