# Module 8: Advanced SE Practices & SE Graduation Project

**Year:** 3 | **Code:** 08.SE | **Learning Line:** Professional Practice Line | **ECs:** 40

Develops advanced software engineering competence through the Season 3 C++ project sequence, building on Module 5 (systems development), Module 6 (team inquiry), and Module 7 (process/quality). Covers object-oriented programming, networked client-server systems, fault-tolerant design, virtual-machine architecture, architecture refinement, intermediate algorithms, and justified software optimization. Projects completed in official Qwasar order: **Bootcamp C++ → My FTP → Abstract Virtual Machine → Redis.**

## Connection with the Research Practice Line

Team inquiry applied to advanced software project work via Plan–Act–Observe–Reflect, same pattern as the ML/DS tracks' Module 8.

## Intended Competencies and Learning Outcomes

**Programming** — use OOP to structure software via class-based design.
**Software architecture design** — design architecture for project requirements; refine architecture through iterative review.
**Data structures and algorithms** — apply intermediate algorithms for performance; optimise key-value storage for efficiency.
**Software development** — scalable client-server interaction; evaluate trade-offs justifiably; fault-tolerant design; optimise for performance.
**Building databases** — apply database persistence mechanisms for reliable storage.

## Module Planning (28 weeks + pre/post-module)

Pre-module: Preparatory C++ Learning. Weeks 1–4: Bootcamp C++ (syntax, references, instances, methods, classes, intro OOP). Weeks 5–10: My FTP (sockets, protocols, async interaction, FTP/RFC implementation). Week 11: Mid-module Progress Review. Weeks 12–17: Abstract Virtual Machine (VM recoded in C++, inheritance, Docker/containers, architecture refinement). Weeks 18–21: Redis — client phase (Redis functionality recoded in C++, CLI, protocol, hash-based features, performance). Weeks 22–25: Redis — server and persistence phase (server architecture, command handling, hash-based structures, persistence, reliability, concurrency, trade-offs). Weeks 26–27: Process and Quality Integration. Week 28: Final Evidence Integration. Post-module: Certification VIVA.

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 3 C++ projects at expected standard, evidencing programming, architecture, data structures/algorithms, databases, software development).
**High-stake:** Certification VIVA (end of Certification 3), covering Modules 6–8.

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
