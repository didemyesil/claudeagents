# Module 5: Applied Data Science (ML Track)

**Year:** 2 | **Code:** 05.ML | **Learning Line:** Professional Practice Line | **ECs:** 52.5

Develops applied data science competence through the Season 2 Qwasar project sequence in the ML track, building on programming/systems foundations (Modules 1, 3) and one-to-one inquiry (Module 4). Integrates Python programming, data engineering, database development, statistical analysis, visualisation, NLP, optimisation, and predictive modelling — working with structured/textual data, SQL, ETL, exploratory analysis, classification, regression, and domain-specific datasets, with increasingly independent choices. Concludes with Season 2 evidence integration and Certification 2 preparation.

## Connection with the Research Practice Line

One-to-one inquiry via Plan–Act–Observe–Reflect during Season 2 projects: identify a meaningful interaction/analytical collaboration, clarify understanding/feedback needed, act through purposeful dialogue and project work, observe responses/analytical outcomes, reflect on adapting communication/data-science choices.

## Intended Competencies and Learning Outcomes (selected)

Programming (OOP, Python for data analysis, symbolic/numeric transformations, file parsing/DB interaction); Data structures and algorithms (search/filtering, in-memory representations, algorithmic solutions, optimisation methods, predictive-modelling maths); Database development (relational queries, joins, persistence); Data engineering (transforms, ETL, integration, preprocessing, controlled data transitions); Data analysis (statistical techniques, trend summarisation, end-to-end analysis, domain-specific insight, relationship investigation, interpreting modelling results); Data visualisation (statistical outputs, frequency patterns, feature relationships, trend/optimisation visualisation, communicating insights); Machine learning solution design (end-to-end ML approach, method/model selection, performance criteria); Machine learning model development (classification/regression training, domain-specific predictive models, validation, optimisation); Natural language processing (text preprocessing); Professional advice (justified recommendation, stakeholder communication).

## Module Planning (36 weeks + post-module)

Weeks 1–2: My Select Query (CSV parsing, class-based queries). Weeks 3–4: My NBA Game Analysis (nested data, player stats). Weeks 5–6: My Mr Clean (text extraction/cleaning/tokenisation, word-frequency visualisation). Weeks 7–9: Bootcamp Data Science (Jupyter, NumPy, pandas, EDA, Matplotlib). Weeks 10–11: My Allocine → My Roman Numerals Converter (relational queries/joins, symbolic/numeric transforms). Weeks 12–14: My DS Babel (SQL–CSV/ETL, DB persistence). Weeks 15–17: My Open The Iris (data prep, EDA, classification, validation). Week 18: Mid-module Progress Review. Weeks 19–21: My Tu Verras (housing data, regression). Weeks 22–24: My M And A (cleaning/merging/deduplication/migration). Weeks 25–29: My Convex Optimization → My Linear Regression (optimisation, gradient descent, regression). Weeks 30–35: My MobApp Studio → My Vivino (market analysis, predictive modelling, recommendations). Week 36: Season 2 Hackathon and Evidence Integration. Post-module (2 wks): Break and certifications. Post-module (4 wks): Certification VIVA.

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup participation, squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 2 DS projects at expected standard).
**High-stake:** Certification VIVA (end of Certification 2).

**Passing criteria:** ≥75% low-stake evidence, ≥75% medium-stake evidence, and Certification VIVA passed.
