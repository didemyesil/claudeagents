# Module 8: Advanced AI/ML Applications & AI/ML Graduation Project

**Year:** 3 | **Code:** 08.ML | **Learning Line:** Professional Practice Line | **ECs:** 40

Develops advanced ML competence through the Season 3 Qwasar project sequence: Visa for Lisa → Classically Punk → My_Paypal → Atari Games (official order preserved). Builds on data science/modelling foundations (Module 5), team inquiry (Module 6), and process/quality practices (Module 7). Covers supervised learning, audio classification, fraud detection, model evaluation, error analysis, deep learning, and reinforcement learning. Learning via agile project rhythm (independent project work, workshops, standups, squads, retrospectives, team coaching), applying Module 7 methodologies/version-control/testing/quality methods with team inquiry to examine modelling and collaborative challenges. Concludes with Season 3 evidence integration and Certification 3 preparation.

## Connection with the Research Practice Line

Team inquiry applied to advanced ML project work via Plan–Act–Observe–Reflect: define an inquiry focus, test a modelling/workflow action, observe effects on model behaviour/team delivery, reflect on what to retain/change — linking ML decisions with evidence-based process improvement.

## Forms of Learning

Module Projects (online, Season 3 Qwasar projects); Self-study (online: data prep, supervised learning, classification, regression, audio features, fraud detection, neural networks, reinforcement learning, model evaluation, optimisation, error analysis); Workshops (online); Standups (campus); Squads (campus); Team Coaching (campus).

## Intended Competencies and Learning Outcomes

**Programming** — develop Python programs using appropriate syntax/control structures/functions/data types.
**Data analysis** — analyse datasets for patterns/trends/relationships; interpret statistical results for professional conclusions.
**Machine learning solution design** — design end-to-end ML approach for a professional problem; select appropriate methods/models/components; define performance criteria relative to application context.
**Machine learning model development** — train ML models for classification/regression; evaluate performance via appropriate validation/metrics; improve behaviour through optimisation/tuning; diagnose limitations via error analysis; apply deep learning to complex learning problems.
**Professional advice** — develop justified recommendation from contextual analysis; communicate recommendation to stakeholders responsibly.

## Module Planning (28 weeks + pre/post-module)

Pre-module: Preparatory ML Review (not a Qwasar project). Weeks 1–7: Visa for Lisa (loan prediction/decision modelling). Weeks 8–14: Classically Punk (audio-feature/music-genre classification). Week 15: Mid-module Progress Review. Weeks 16–20: My_Paypal (fraud detection, class imbalance). Weeks 21–24: Atari Games — model development (RL foundations, DQN). Weeks 25–26: Atari Games — training/evaluation. Week 27: Process and Quality Integration. Week 28: Final Evidence Integration. Post-module: Certification VIVA.

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup participation, squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 3 ML projects at expected standard).
**High-stake:** Certification VIVA (end of Certification 3), presenting project/process/quality/team-inquiry evidence for Modules 6–8.

**Passing criteria:** progression at certification level requires ≥75% of required low-stake evidence completed at the required standard, ≥75% of required medium-stake evidence passed, and the Certification VIVA passed. Decision based on portfolio review by assigned assessor(s) and panel-assessed VIVA.
