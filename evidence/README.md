# /evidence

Mevcut 6-ajan analiz katmanının çıktıları buraya, programa göre alt klasörlerde
tutulur:

```
/evidence/{programme}/
```

`folder-developer` (Aşama 2) checklist'teki her standardı buradaki kanıtla
eşler. Bir programın kanıt havuzu henüz burada değilse, Aşama 2 o programa
ait maddeleri "evidence needed" olarak işaretler — uydurmaz.
