# Module 1: Foundations of Data Science (DS Track)

**Year:** 1 | **Code:** 01.DS | **Learning Line:** Professional Practice Line | **ECs:** 15

Content, connection with the Research Practice Line, forms of learning, intended competencies/learning outcomes (Programming; Data structures and algorithms; Data engineering; Solution requirements analysis), weekly study load (41 hrs: Projects 25, Self-study 4, Workshops 2, Standups 2, Squads 4, Team Coaching 4), and assessment structure (low/medium/high-stake, ≥75%/≥75%/VIVA passing criteria) are identical to the Applied Machine Learning track's Module 1 (see `../applied-machine-learning/Module 1 - Foundations of Data Science.md`), differing only in track code (01.DS vs 01.ML) and the project-order source reference (Data Science tab of the Qwasar Curricula Learning Outcomes and Skills sheet, per the approved TNO mapping, rather than the AI/ML curriculum sequence).

## Module Planning (13 teaching weeks + post-module)

Same weekly sequence as the ML track: Weeks 1–2 Orientation (programme/learning environment; Qwasar introduction); Week 3 Bootcamp Python; Week 4 Quest 01→02; Week 5 Quest 03→04; Week 6 My Hamming DNA; Week 7 Quest 05; Week 8 Quest 06; Week 9 My IMDB API (data handling); Week 10 My IMDB API (service behaviour); Week 11 Project integration/refinement; Week 12 Progress review; Week 13 Certification VIVA prep; Post-module Break, Certifications, Certification VIVA (4 wks).
