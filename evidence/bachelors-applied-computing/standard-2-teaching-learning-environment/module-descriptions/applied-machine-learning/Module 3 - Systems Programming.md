# Module 3: Systems Programming (ML Track)

**Year:** 1 | **Code:** 03.ML | **Learning Line:** Professional Practice Line | **ECs:** 37.5

Develops systems programming competence through the Season 1 project sequence, building on Module 1 (Python/data-handling) and Module 2 (self-inquiry). Centres on C programming and progressively complex systems tasks: structured problem solving, functions, conditionals, loops, pointers, memory operations, command-line workflows, file input, data structures, algorithms, requirements interpretation.

## Connection with the Research Practice Line

Seasonal self-inquiry continues via Plan–Act–Observe–Reflect within Season 1 sprints: inquiry focus tied to learning/teamwork/technical issues, observed via standups/retrospectives/team coaching alongside technical project evidence.

## Intended Competencies and Learning Outcomes

**Programming** — functions/conditionals; abstraction/decomposition; command-line tools and version control; loops/pointers/memory operations; file input/system-level operations.
**Data structures and algorithms** — structured algorithm design; efficient data structures.
**Solution requirements analysis** — interpret functional/contextual requirements.

## Module Planning (27 weeks + post-module)

Weeks 1–5: Bootcamp C (Quest00–04). Week 6: My Square (nested loops, 2D tables). Week 7: My Cat (file input). Week 8: My Ngram (char-frequency counting, CLI, data representation). Weeks 9–10: Mastermind (arrays, game logic, algorithms). Weeks 11–13: My PrintF (variadic functions, type conversion, output formatting). Mid-module review. Weeks 14–17: Project refinement/testing. Weeks 18–20: Algorithms/data-structure practice. Weeks 21–23: File/CLI practice. Weeks 24–26: Integrated systems challenge. Week 27: Season 1 Hackathon and Evidence Integration. Post-module: Break, Certifications, Certification VIVA (4 wks).

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 1 technical projects at expected standard).
**High-stake:** Certification VIVA (end of Certification 1).

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
