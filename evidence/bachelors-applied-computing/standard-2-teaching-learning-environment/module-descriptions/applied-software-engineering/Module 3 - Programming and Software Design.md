# Module 3: Programming and Software Design

**Year:** 1 | **Code:** 03.SE | **Learning Line:** Professional Practice Line | **ECs:** 37.5

Develops programming and software design competence through the Season 1 project sequence, building on Module 1 (intro programming) and Module 2 (self-inquiry). Centres on C programming and progressively larger systems projects: structured problem solving, memory management, command-line workflows, data structures, algorithms, input handling, solution requirements analysis, and software architecture design, requiring increasingly independent, justified implementation/design choices.

## Connection with the Research Practice Line

Seasonal self-inquiry via Plan–Act–Observe–Reflect within Season 1 sprints (same pattern as other tracks' Module 3).

## Intended Competencies and Learning Outcomes

**Programming** — structured reasoning; core programming constructs; reusable code via abstraction; command-line tools; memory allocation control; system input functions.
**Data structures and algorithms** — algorithmic solutions via abstraction; string-based algorithms; pattern-generating functions via abstraction; data structures.
**Software architecture design** — design architecture to address project requirements through structured component choices.
**Solution requirements analysis** — analyse a project context to identify solution requirements.

## Module Planning (27 weeks + post-module)

Weeks 1–5: Bootcamp C Arc 1 (Quest00–04: terminal, loops, types, pointers/strings, arrays, memory, algorithms, shell, 2D arrays). Week 6: My Square. Week 7: Quest05 (shell/pipes/find). Week 8: MasterMind (arrays, game logic, architecture). Weeks 9–10: My PrintF (variadic args, type/base conversion). Weeks 11–13: Bootcamp C Arc 2 (Quest06–08, My Cat, My Christmas Tree — recursion, string algorithms, file reading, pattern abstraction). Mid-module review. Weeks 14–17: My LS (Unix, architecture, sorting, Makefile). Weeks 18–20: My Tar (archives, POSIX architecture). Weeks 21–23: Readline (string manipulation, read/system calls). Weeks 24–27: My Blockchain (linked lists, graphs, CLI parsing, blockchain data structure). Final phase: Season 1 Hackathon and Evidence Integration. Post-module: Break, Certifications, Certification VIVA (4 wks).

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 1 projects at expected standard, evidencing Programming, Data structures and algorithms, Software architecture design, Solution requirements analysis).
**High-stake:** Certification VIVA (end of Certification 1).

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
