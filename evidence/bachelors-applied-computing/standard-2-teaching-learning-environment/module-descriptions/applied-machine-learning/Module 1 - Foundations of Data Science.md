# Module 1: Foundations of Data Science (ML Track)

**Year:** 1 | **Code:** 01.ML | **Learning Line:** Professional Practice Line | **ECs:** 15

Introduces data science foundations: 2-week orientation (programme, learning environment, Qwasar platform) followed by 11 weeks of project-based technical learning (Python programming, algorithmic thinking, data structures, CSV transformation, file parsing, simple API for structured data). Establishes an initial link between programming, data preparation, and applied data science practice via workshops, standups, squads, team coaching, and project-based learning.

## Connection with the Research Practice Line

Connected to self-inquiry via Plan–Act–Observe–Reflect applied simply and practically: plan work, act through project execution, observe results/feedback, reflect on development.

## Intended Competencies and Learning Outcomes

**Programming** — Python syntax/control structures/functions/data types; functions and conditionals; abstraction/decomposition; file parsing/DB interaction.
**Data structures and algorithms** — structured algorithm design; efficient data structures; representing structured data for computation/transformation.
**Data engineering** — transform structured datasets for downstream analysis.
**Solution requirements analysis** — interpret functional/contextual requirements for correct solution behaviour.

## Module Planning (13 teaching weeks + post-module)

Weeks 1–2: Orientation (programme/learning environment; Qwasar introduction). Week 3: Bootcamp Python. Week 4: Quest 01→02. Week 5: Quest 03→04. Week 6: My Hamming DNA (cipher algorithm). Week 7: Quest 05 (array manipulation). Week 8: Quest 06 (CSV parsing). Week 9: My IMDB API — data handling. Week 10: My IMDB API — service behaviour. Week 11: Project integration/refinement. Week 12: Progress review. Week 13: Certification VIVA prep. Post-module: Break, Certifications, Certification VIVA (4 wks).

## Weekly Study Load (41 hrs total, project phase)

Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** weekly workshop reflections, standup participation, squad participation, team coaching contributions.
**Medium-stake:** Projects (required projects completed at expected standard).
**High-stake:** Certification VIVA (end of Certification 1).

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
