# Module 1: Foundations of Software Development (SE Track)

**Year:** 1 | **Code:** 01.SE | **Learning Line:** Professional Practice Line | **ECs:** 15

Introduces software engineering foundations: 2-week orientation (programme, learning environment, Qwasar) followed by 11 weeks of project-based technical learning developing program logic, core programming constructs, reusable code, command-line workflow, event-based/timed logic, basic interface styling, and URL/route structures — building an initial bridge between implementation and the broader professional practice of software engineering.

## Connection with the Research Practice Line

Connected to self-inquiry via Plan–Act–Observe–Reflect, same pattern as the DS/ML tracks' Module 1.

## Intended Competencies and Learning Outcomes

**Programming** — develop program logic; apply core programming constructs; develop reusable code via abstraction; use command-line tools; implement event-based/timed logic; develop basic interface styling; apply URL structures for navigation.
**Data structures and algorithms** — develop algorithmic solutions via abstraction; apply data structures to solve computational problems.

## Module Planning (13 teaching weeks + post-module)

Weeks 1–2: Orientation. Week 3: Quest01/02 (variables, data types, console output). Week 4: Quest03/04 (loops, functions, terminal scripts, conditionals). Week 5: Quest05/06 (string formatting/manipulation). Week 6: Quest07 (arrays). Week 7: My Hamming DNA (cipher algorithm). Week 8: My Moving Box Realtime (JS/HTML, async timed functions). Week 9: My Robot Simulator (command strings → 2D-map movement). Week 10: My Bouncing Box (geometry-based movement). Week 11: My CSS Is Easy (HTML/CSS, flexible layout). Week 12: My First Backend (API routes/endpoints). Week 13: Integration + VIVA prep. Post-module: Break, Certifications, Certification VIVA (4 wks).

## Weekly Study Load (41 hrs total)

Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** weekly workshop reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Projects (required projects at expected standard, evidencing Programming and Data structures and algorithms).
**High-stake:** Certification VIVA (end of Certification 1).

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
