# Module 5: Applied Data Science (DS Track)

**Year:** 2 | **Code:** 05.DS | **Learning Line:** Professional Practice Line | **ECs:** 52.5

Develops applied data science competence through the Season 2 project sequence, building on Modules 1/3 (programming/systems) and Module 4 (one-to-one inquiry). Integrates Python, data engineering, database development, statistics, visualisation, NLP, optimisation, predictive modelling; works with structured/textual data, SQL, ETL, exploratory analysis, classification, regression, domain-specific datasets.

## Connection with the Research Practice Line

One-to-one inquiry via Plan–Act–Observe–Reflect during Season 2 projects, same pattern as the ML track's Module 5 (see `../applied-machine-learning/Module 5 - Applied Data Science.md`).

## Intended Competencies and Learning Outcomes

Identical set to the ML track's Module 5 except: **"Machine learning solution design"** is replaced by **"Data science solution design"** — design a data science approach for a professional problem based on requirements/context; select appropriate analytical/modelling/visualisation methods; define evaluation criteria relative to application context. All other competency areas (Programming, Data structures and algorithms, Database development, Data engineering, Data analysis, Data visualisation, Machine learning model development, Natural language processing, Professional advice) are the same.

## Module Planning (36 weeks + post-module)

Same Qwasar project sequence as the ML track's Module 5 (My Select Query → My NBA Game Analysis → My Mr Clean → Bootcamp Data Science → My Allocine/My Roman Numerals Converter → My DS Babel → My Open The Iris → Mid-module Review → My Tu Verras → My M And A → My Convex Optimization/My Linear Regression → My MobApp Studio/My Vivino → Season 2 Hackathon → Certification VIVA), with LOs referencing "Data science solution design" instead of "Machine learning solution design" at the relevant weeks.

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

Same low/medium/high-stake structure and ≥75%/≥75%/VIVA passing criteria as the ML track's Module 5, contributing to the Certificate 2 portfolio.
