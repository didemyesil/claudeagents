## The shape of this pass

Same rules as the Standard 1 map.

- A document covering several programmes is **one file**. Institution-level documents are never copied per programme.
- Every absence is classified as one of three kinds:
  - **Missing document** — the practice exists but is not written down.
  - **Missing institutional fact or decision** — only Didem can supply it.
  - **Missing track record** — the programme has not launched.
- Where two sources state the same fact differently, both are recorded in the discrepancy register (below). Neither is trusted.

**Bucket vocabulary** (the four buckets requested):

- **Held** — on file, citable as it stands.
- **Needs adapting** — an existing source in the wrong shape, or a short new document Stage 2 can draft purely from facts already on file with no input from Didem. Both count here.
- **False gap** — shared evidence exists and has simply not been pointed to or extended.
- **Genuine gap** — needs a fact or decision from Didem.
