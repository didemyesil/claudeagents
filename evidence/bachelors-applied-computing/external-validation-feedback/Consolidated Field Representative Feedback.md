## Decision and Action Plan

The original verbatim feedback remains unchanged. This table records the programme decision, required action, and current status for each development theme.

| Related Feedback | Decision | Action | Status |
|---|---|---|---|
| AI Engineering positioning and career umbrella | Partially accept. Use as supporting evidence for the AI Engineering direction; retain current approved track structure until formal curriculum approval. | Prepare a programme-positioning decision note; after approval, revise the Programme Brochure's track descriptions and career opportunities. | In progress |
| Programme Outcome terminology | Retain the formal term "Programme Outcomes"; the six outcomes may be explained as professional capabilities in the brochure. | Add a short explanatory sentence without renaming the approved outcomes (Analyse, Advise, Design, Build, Manage and Control, Communicate and Collaborate). | Planned |
| Software Engineering profile, SDLC and AI-coding tools | Accept. Strengthen the SDLC foundation and make responsible AI-assisted development visible without making the curriculum dependent on specific products. | Map SDLC across the track; add learning activities covering AI coding tools, testing, code review, security and production-grade development; use current tools only as examples. | Planned |
| Four-year and three-year programme structure | Accept as a priority correction. Present one 240-ECTS HBO bachelor with a four-year standard route and a three-year accelerated route for eligible entrants, same final outcomes/graduation standard. | Revise the Programme Overview and route tables to show admission basis, duration, ECTS distribution, workload, sequence, and how the accelerated route condenses/integrates foundation learning. | **Priority** |
| Data structures and algorithms sequencing | Accept. Data structures and algorithms should precede or run alongside programming wherever foundational concepts are required. | Check the approved project–LO mapping and Qwasar sequence; adjust module order, prerequisites and brochure wording where required. | To validate |
| Programming vs Software Development classification | Accept the need for clarification. Reclassify outcomes according to primary competence while avoiding duplication. | Audit the cited outcomes on URL structures, reusability, event-driven architecture, client-server interaction, trade-offs, reliability, optimisation; update modular LO sheet and module descriptions. | Planned |
| Inquiry within process management | Partially accept. Keep Inquiry as a distinct competency while making its role within SDLC process management explicit. | Map relevant Inquiry outcomes to Software Development Process Management learning activities/assessment evidence without duplicating outcomes. | Planned |
| Visibility of statistics | Validate first. If statistics is already embedded, make it visible; if a genuine gap exists, add explicit LOs and teaching coverage. | Map statistics across DS/ML modules, projects, assessments; update brochure and module descriptions based on result. | To validate |
| Data Science and Machine Learning differentiation | Accept. Differentiate DS from ML and AI Engineering through distinct capability emphasis. | Clarify DS focus; add optimisation, deployment, monitoring, MLOps to ML/AI Engineering competency and module mapping where not already covered. | Planned |
| Traineeship duration | Review required before changing the duration; 125 hours needs a regulatory, programme-design and industry benchmark check. | Confirm what the 125 hours represents, benchmark comparable HBO practice, assess implications for ECTS/workload/supervision/assessment before revising documents. | To validate |
| MVP as an alternative preparation route | Accept in principle as an optional real-world output only if it demonstrates the same Programme Outcomes and assessment standard. | Define equivalence requirements, evidence and rubric expectations for an MVP route; if approved, update Final Project Guide, assessment mapping, Programme Brochure. | Planned |
