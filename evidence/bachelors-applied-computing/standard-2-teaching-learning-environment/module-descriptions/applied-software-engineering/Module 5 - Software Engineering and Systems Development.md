# Module 5: Software Engineering and Systems Development

**Year:** 2 | **Code:** 05.SE | **Learning Line:** Professional Practice Line | **ECs:** 52.5

Develops integrated software engineering/systems development competence through the Season 2 project sequence, building on Module 3 (C/software design/requirements) and Module 4 (one-to-one inquiry). Extends into higher-level languages, algorithms, language processing, databases, networking, systems programming, memory management, and fault-tolerant design — Ruby, shell/Unix, CSS, SQL, HTTP, sockets, assembly, memory allocation.

## Connection with the Research Practice Line

One-to-one inquiry via Plan–Act–Observe–Reflect during Season 2 projects (same pattern as other tracks' Module 5).

## Intended Competencies and Learning Outcomes

**Programming** — program logic; core constructs; language-processing/parsing components; basic interface styling; low-level/close-to-machine programming.
**Data structures and algorithms** — self-learning/adaptive algorithms; reading/explaining algorithm logic; building algorithms; stack data structure; applying data structures; intermediate algorithms for performance.
**Software architecture design** — design architecture for project requirements.
**Building databases** — apply database principles to manage data.
**Solution requirements analysis** — analyse project context for requirements.
**Software development** — scalable client-server interaction; evaluate trade-offs justifiably; fault-tolerant design for reliability.

## Module Planning (36 weeks + post-module)

Weeks 1–3: Bootcamp Ruby. Weeks 4–6: My BSQ (rule-/probability-based self-learning algorithm). Weeks 7–9: My BC (lexer/parser, stack data structure). Weeks 10–12: My Mouse (adaptive/self-learning algorithm). Weeks 13–16: ZSH (CLI parsing, Unix processes/forks/pipes, intermediate architecture). Week 17: Mid-module Progress Review. Weeks 18–19: CSS is Easy I (flexbox, interface styling). Weeks 20–23: SQL Lite (custom DB/SQL parser, hash-based structures, database principles). Weeks 24–27: My Curl (sockets, HTTP, client-server, fault-tolerant architecture). Weeks 28–31: LibASM (C library reimplementation in assembly). Weeks 32–35: Malloc (linked lists/hash tables/trees for memory allocation, performance trade-offs). Week 36: Season 2 Hackathon and Evidence Integration. Post-module: Break, Certifications, Certification VIVA (4 wks).

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 2 projects at expected standard, evidencing all module competencies).
**High-stake:** Certification VIVA (end of Certification 2).

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
