# Module 7: Software Development Process and Quality Management & SE Solution Design using Action Inquiry

**Year:** 3 | **Code:** 07.SE | **Learning Line:** Professional Practice Line | **ECs:** 12.5

Develops software development process management and quality practice for Year 3, building on Module 5 (systems development) and Module 6 (team inquiry). Content, connection with the Research Practice Line, forms of learning, intended competency (Software development process management: apply appropriate methodologies; use version control/testing), 8-week module planning, weekly study load (41 hrs), and assessment structure are the same template as the ML/DS tracks' Module 7 (see `../applied-machine-learning/Module 7 - Software Development Process and Quality Management and AI-ML Solution Design using Action Inquiry.md`).

## Module Planning (8 weeks)

Week 1: SDLC and Method Selection. Week 2: Agile Software Development. Week 3: Lean Software Development. Week 4: Planning, Monitoring, and Delivery Control. Week 5: Version Control and Code Review. Week 6: Testing Strategy and Software Reliability. Week 7: Continuous Integration and Quality Controls. Week 8: Integrated Process and Quality Management Project.

## Weekly Study Load (41 hrs total)

Process and quality coursework/Module Project (blended): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Module Project — analysis/improvement of a software development process and quality practices.
**High-stake:** Certification VIVA (end of Certification 3).

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
