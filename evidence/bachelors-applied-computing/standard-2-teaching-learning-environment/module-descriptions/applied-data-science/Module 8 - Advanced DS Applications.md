# Module 8: Advanced DS Applications

**Year:** 3 | **Code:** 08.DS | **Learning Line:** Professional Practice Line | **ECs:** 40

Develops advanced applied data science competence through the Season 3 project sequence, building on Module 5 (DS competence), Module 6 (team inquiry), and Module 7 (process/quality). Covers advanced optimisation, fraud detection, large-scale data integration, NLP, model evaluation, stakeholder analysis, professional communication. Projects completed in official Qwasar order: **Drive Me Crazy → A Fool's Fraud → Coleridge Initiative.**

## Connection with the Research Practice Line

Team inquiry applied to advanced DS project work via Plan–Act–Observe–Reflect, same pattern as the ML track's Module 8.

## Intended Competencies and Learning Outcomes

Data structures and algorithms (apply optimisation methods); Data analysis (interpret modelling results); Data science solution design (select analytical/modelling/visualisation methods; define evaluation criteria); Machine learning model development (classification training, validation/metrics, error analysis); Data engineering (identify data sources for large-scale work, transform unstructured data, integrate multi-source datasets); Data visualisation (develop visual evaluation frameworks for stakeholders); Natural language processing (text preprocessing); Professional advice (justified recommendation, stakeholder communication).

## Module Planning (28 weeks + post-module)

Weeks 1–3: Drive Me Crazy — problem framing (traffic-flow requirements, simulation constraints, optimisation criteria). Weeks 4–8: Drive Me Crazy — optimisation and evaluation (traffic-light scheduling, simulation, algorithm testing). Week 9: Progress Review. Weeks 10–15: A Fool's Fraud — modelling and risk (fraud classification, model selection, validation, false positives/negatives, business cost). Week 16: A Fool's Fraud — professional recommendation. Weeks 17–24: Coleridge Initiative — data and NLP (large-scale source identification, extraction from research publications, unstructured-text transformation, dataset integration, NLP analysis). Weeks 25–26: Coleridge Initiative — evaluation and communication (evaluation framework, visual scorecard). Week 27: Process and Quality Integration. Week 28: Final Evidence Integration. Post-module: Certification VIVA.

## Weekly Study Load (41 hrs total)

Module Projects (online): 25 | Self-study (online): 4 | Workshops (online): 2 | Standups (campus): 2 | Squads (campus): 4 | Team Coaching (campus): 4

## Assessment

**Low-stake:** workshop/sprint reflections, standup/squad participation, team coaching contributions.
**Medium-stake:** Module Projects (Season 3 DS projects at expected standard).
**High-stake:** Certification VIVA (end of Certification 3), covering Modules 6–8.

**Passing criteria:** ≥75% low-stake, ≥75% medium-stake, Certification VIVA passed.
