# Projeler
Her proje için bir klasör: `projects/<slug>/` içinde
- `instructions.md`: proje talimatı (ChatGPT'den taşınan veya burada yazılan)
- `decisions.md`: güncel kararlar (tarihli; eski/terk edilenler `superseded` ile işaretli)
- `sources.md`: kaynak belgeler ve linkler (Drive, Trello, Slack, ChatGPT arşivi referansı)
Yeni proje: ilk iş açıldığında koordinatör oluşturur.
